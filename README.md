# Tested on one shared quantity: what adversarial tests of consciousness can and cannot yet measure

Supplementary materials and analysis code for the manuscript submitted to *Brain Sciences* (MDPI), ms. brainsci-4583950 (revision 1, September 2026).

The manuscript codes theories of consciousness against eight measurable quantities (M1–M8) and asks which quantities theories share, contest, occupy alone, or leave unoccupied. Everything the argument rests on is here, cell by cell, with a justification and a DOI.

## Layout

| Path | Contents |
|---|---|
| `supplementary/Table_S1_theory_by_quantity.csv` | **Table S1** — 88 cells: 11 coded accounts × 8 quantities; `code` ∈ {YES, IMPLICIT, NO, YES (negative)}, one-sentence `prediction`, `citation_label`, `citation_doi`, `row_class` (trial-level / origin-level), `cell_origin` (submitted-v1 / added-in-revision). |
| `supplementary/Table_S1_v0_submission_72cells.csv` | The 72-cell matrix of the original submission, kept for provenance. |
| `supplementary/Table_1_tallies.csv` | Column tallies printed as Table 1 in the manuscript, regenerated by `scripts/recompute_table1.py`. |
| `supplementary/Table_S2_content_inventory.csv`, `S2_inclusion_criteria.txt` | **Table S2** — 36 rows (31 empirical, 5 paradigm-defining, flagged in `row_type`) with content category and theory-addressed flag; the inclusion rule. |
| `supplementary/Table_S3_contrast_dimensions.csv`, `Table_S3_tallies.csv` | **Table S3** — the same accounts coded against the 12 annotation dimensions of the ConTraSt database (Yaron et al. 2022), 120 cells. |
| `supplementary/codebook.md` | Codebook for the blind second coding. |
| `coding/second_coder_pack/` | Blank forms (S1, S2, optional S3), timing log and instructions for the second coder. |
| `scripts/agreement.py` | Inter-coder agreement (Cohen's κ, weighted κ, per-column κ, κ for the submitted-v1 and added-in-revision subsets, disagreement list); numpy/pandas only. |
| `scripts/table1_from_matrix.py` | Compact matrix view + tallies + least-favourable reclassification from any Table S1 version. |
| `scripts/mdpi_refs.py`, `scripts/fetch_crossref.py` | Author–date → MDPI numbered references, from CrossRef records. |
| `power_analysis/` | Power analysis for the worked condition of §9.1 (analytic, two-stage and mixed-model simulation). |
| `manuscript/` | Revision-1 manuscript (markdown, MDPI references) and the PDF with revised passages highlighted. |
| `review_round1/` | Round-1 reviews (transcribed) and the point-by-point response. |

## Reproduce Table 1

```bash
python scripts/table1_from_matrix.py supplementary/Table_S1_theory_by_quantity.csv
```

## Inter-coder agreement (after the second coding)

```bash
python scripts/agreement.py --s1a supplementary/Table_S1_theory_by_quantity.csv \
    --s1b coding/second_coder_pack/S1_blank_for_coder2.csv \
    --s2a supplementary/Table_S2_content_inventory.csv \
    --s2b coding/second_coder_pack/S2_blank_for_coder2.csv --out agreement_out/
```
