Начните с **RESULTS_RU.md**. Это независимые решения ИИ по доступным первичным источникам, а не свидетельство участия второго человека или гарантированной слепоты.

## Запуск

В каталоге распакованного пакета:

```bash
python build_results.py
python validate_results.py
```

Эти два скрипта используют только стандартную библиотеку Python. Они не загружают литературу и не принимают исследовательских решений. Для будущего межкодерного сравнения предоставленный `protocol/agreement.py` требует своих зависимостей и реального независимого файла первого кодера; сравнивать файл с самим собой нельзя.

При сравнении разделения публикаций используйте все 32 записи `S2_publication_partition.csv`: отсутствие строки эксперимента P35 означает осознанный ноль, а не пропуск. Не ограничивайте этот анализ пересечением идентификаторов экспериментов. Различающиеся порядки и неоднозначные единицы P12/P13/P20/P21/P22 нужно согласовать до сравнения экспериментальных строк.

Исходные схемы CSV сохранены; служебные колонки `evidence_status`, `provisional`, `flag_for_adjudication` и пояснения добавлены справа там, где их не было. UTF-8 с BOM выбран для удобного открытия CSV. Полные тексты чужих статей не включены.

## Ограничения, которые нужно сохранить при передаче

- У S1 одна формально предварительная ячейка; это не удостоверяет полноту корпуса для остальных 119. Три книжных/главных источника не прочитаны, 31 источник доступен только в аннотации.
- У S2 13 строк основаны на аннотациях, 25 строк относятся к публикациям с непроверенным или спорным разделением. Это две разные характеристики.
- Пограничные строки и нулевое число подтверждённых автономных конфликтов не являются доказательством отсутствия соответствующих исследований вообще.
- Отсутствующая поздняя атрибуция означает «не найдено в доступном корпусе», а не полный библиометрический поиск.
- Измеренного времени отдельно на каждую теорию нет; интервалы не восстановлены задним числом.
- Опциональная S3, S4 и межтеоретические пары не кодировались. κ и итоговая типология столбцов не вычислялись.
- В предоставленном `agreement.py`, просмотренном для совместимости, есть комментарий с примером ранее использованного значения P08-E3. Это дополнительная причина не заявлять строгую слепоту ИИ-сессии. Моя строка P08-E3 кодируется по прочитанным Methods как `both`, а не по этому примеру.
- Общая сетка пакета не изменена. Есть противоречие инструкций §4 о поздней атрибуции; выполнено повторённое конкретное требование заполнять её независимо.

Это кодирование корпуса на дату выполнения, а не оценка истинности теорий сознания.
